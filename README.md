# ⚽ Football Tactical Analytics Dashboard

Aplicación interactiva de scouting y análisis táctico desarrollada con Python y Streamlit a partir de datos abiertos de **StatsBomb**.

## 🚀 Características
- **Filtro dinámico de partidos y jugadores.**
- **KPIs de rendimiento:** Precisión de pases y pases progresivos.
- **Visualización espacial:** Mapas de pases vectoriales y Heatmaps de posicionamiento.

## 🛠️ Tecnologías
- Python, Streamlit, Pandas, Matplotlib, Seaborn, mplsoccer, statsbombpy.

## 💻 Ejecución local
```bash
pip install -r requirements.txt
streamlit run app.py
